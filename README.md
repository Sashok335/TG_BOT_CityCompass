# CityCompass

CityCompass — это многоязычный Telegram-бот для путешественников, который помогает находить интересные места и достопримечательности в любой точке мира.

Бот не просто ищет места поблизости, а агрегирует данные сразу из нескольких открытых источников (OpenTripMap, Wikipedia, Wikidata, DBpedia, Wikimedia Commons), выдавая подробные описания с фотографиями и адресами.

---

## Основные возможности

* Геокодинг городов: Нахождение точных координат любого населённого пункта через OpenStreetMap (Nominatim).
* Мульти-источники данных: Если в одной базе нет описания места, бот последовательно опрашивает Wikipedia, Wikidata и DBpedia.
* Фотогалереи: Автоматический подбор и отправка до 3-х качественных фотографий с Wikimedia Commons.
* Умный кэш (JSON): Повторные запросы к API не совершаются — данные сохраняются локально на 24 часа для высокой скорости работы.
* Динамический радиус поиска: Возможность искать больше мест вокруг города, расширяя радиус при повторном запросе.
* Мультиязычность: Полная поддержка смены языков без потери текущего состояния поиска.

---

## Технологический стек

* Язык: Python 3.8+
* Библиотека бота: python-telegram-bot (v13.x)
* API и сервисы:
  * OpenTripMap API — база достопримечательностей.
  * OpenStreetMap Nominatim API — поиск координат и адресов.
  * MediaWiki / Wikimedia API — статьи и изображения.
  * Wikidata SPARQL & DBpedia SPARQL — семантические описания объектов.

## Быстрый запуск

### 1. Клонирование репозитория
git clone https://github.com/Sashok335/TG_BOT_CityCompass.git
cd TG_BOT_CityCompass

### 2. Установка зависимостей
pip install python-telegram-bot requests

### 3. Настройка токенов
Создайте файл tokens.py в корневой папке проекта со следующим содержимым:

TELEGRAM_TOKEN = "ВАШ_ТЕЛЕГРАМ_ТОКЕН"
OPENTRIPMAP_API_KEY = "ВАШ_OPENTRIPMAP_API_KEY"

### 4. Запуск бота
python bot_main.py

---

## Как пользоваться ботом

1. Отправьте команду /start и выберите язык интерфейса.
2. Введите название любого города (например, Париж, Токио, Алматы).
3. Бот пришлёт карточки с интересными местами, их описанием, адресом и фотографиями.
4. Нажимайте кнопку «Показать ещё», чтобы расширить радиус поиска и увидеть новые места.
